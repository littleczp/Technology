> 抠图不够干净，会残留绿色的描边

2. GIMP

{% stepper %}
{% step %}
### 添加透明通道

1. 顶部菜单：图层 → 透明 → 添加透明通道
2. 如果 "添加透明通道" 置灰则说明图片本身有 Alpha 通道，直接下一步
{% endstep %}

{% step %}
### 提取绿幕的"绿色"

1. "按颜色选择" 工具（快捷键 `Shift+O`）
2. 设置阈值，不断提取颜色和调整直到基本覆盖所有绿幕
3. 右键 → 编辑 → 清除
{% endstep %}

{% step %}
### 去除绿色描边

1. 顶部菜单：选择 → 反转（选中元素）
2. 顶部菜单：颜色 → 颜色到透明，使用"从图片提取颜色"提取绿色，调整阈值观察边缘的绿色描边。

如果描边依然存在

1. 顶部菜单：选择 → 反转（选中绿幕）
2. 顶部菜单：选择 → 生长，输入 1 或 2 像素。这会让选区稍微扩大一点，包住绿边。
3. 顶部菜单：滤镜 → 模糊 → 高斯模糊，强度设为 1 或 2 像素。使得绿边与边缘融合。
{% endstep %}

{% step %}
### 删除无用区域和缩放

1. 顶部菜单：图像 → 裁剪到内容
2. 使用游戏引擎导入后缩放
{% endstep %}
