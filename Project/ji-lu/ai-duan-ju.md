# AI短剧

{% code title="" overflow="wrap" %}
```md
根据【产品档案.pdf】写一条 30 秒小剧场分镜脚本，供视频生成模型直接使用。

输入：
- 人物（可选）：【空则按档案「潜在购买人群」选 1 组最贴的】
- 产品实拍要点：

戏剧结构（必须遵守，总时长 28–30s）：
1. 0–6s 钩子冲突：具体尴尬/失败瞬间（动作可见），不旁白说教。
2. 6–12s 升级：冲突加重或第二次失败，情绪到顶点。
3. 12–22s 产品入场兑现：只打 Top1 卖点（档案有依据），用「使用动作」展示，禁止空口功效。
4. 22–30s 轻反转结局：同一场景变顺 + 一句记忆点收束；可带≤1 个辅卖点闪现。

硬性约束：
- 张力来自情境与动作，不靠夸张虚假前后对比、医疗/保证性承诺。
- 禁用档案「广告禁用说法」；待确认不上口播。
- 产品外观不得改结构/Logo；出镜至少 2 次特写（关键卖点部件）。
- 口播：中文每句≤10字；英文≤7词。全片口播≤6句。
- 极简输出：无开场白、无解释、无总结。

输出：
一、一句话故事（≤20字，含冲突核）
二、人物／场景／情绪弧线（各≤12字）
三、分镜表（6–8 镜，时长列合计≈30s）
| 镜号 | 秒 | 画面（镜头+动作≤28字） | 口播/字幕 | 屏幕大字（可空，≤6字） | 产品（否/是+角度） | 情绪节拍 |
四、BGM／音效（≤3 词组：冲突段／转折段／收束段）
五、合规备注（≤3 条，对应档案禁用）
六、视频模型投喂版（按镜号英文一段；含主体、动作、表情、光影、产品一致性；统一 Negative：deformed product, wrong logo, extra fingers, garbled text, morphing packaging）
```
