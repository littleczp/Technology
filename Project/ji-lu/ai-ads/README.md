## 四种广告类型

1.  产品展示广告（Product Showcase）

    重点：产品外观、材质、细节和使用场景。

    适合美妆、数码、家居、珠宝等品类。AI 可以用于制作微距、环绕、液体飞溅和复杂布光等视觉镜头。



2.  电商转化广告（Performance Ad）

    重点：用户痛点、产品解决方案、购买理由和行动引导。

    适合 TikTok、Meta、短视频信息流等渠道。除了视觉效果，更强调前几秒吸引注意和传递卖点。



3.  品牌形象广告（Brand Film）

    重点：情绪、品牌价值、视觉风格和记忆点。

    适合品牌发布、节日营销和品牌升级。通常对美术、摄影、配乐与整体一致性要求更高。



4.  商业剧情短剧（Branded Short Drama）

    重点：人物、冲突、故事、情绪和自然的产品植入。

    制作难点包括角色一致性、对白、口型、表演、空间连续性与剧情节奏。
